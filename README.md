# 📊 Interactive Excel Call Centre Dashboard

## 📌 Project Overview
This project is an interactive Call Centre Dashboard built using Microsoft Excel. It helps analyze call centre performance using KPI cards, Pivot Tables, Pivot Charts, Slicers, and interactive visualizations.

## 📷 Dashboard Preview

![Dashboard](dashboard-preview.png)

## ✨ Features

- KPI Cards
- Interactive Slicers
- Pivot Tables
- Pivot Charts
- Monthly Call Analysis
- Purchase Amount Analysis
- Call Duration Analysis
- Customer Satisfaction Analysis
- Representative Performance Dashboard

## 🛠 Tools Used

- Microsoft Excel 2021
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Functions
